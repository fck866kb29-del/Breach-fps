# BREACH — DOCK 07

Ett lättviktigt FPS byggt för webbläsaren med WebGL.

## Spela lokalt

Öppna `index.html` i en webbläsare med WebGL-stöd. Spelet körs helt på klientsidan utan externa bibliotek eller nedladdade 3D-modeller.

**Dator:** WASD för rörelse, mus för att sikta, klick för att skjuta. Övriga kontroller visas i spelet.

**Mobil:** Använd pekskärmens styrning.

## Status

- Spelbar singleplayer-prototyp med bottar.
- WebGL-baserad industribana med procedurgenererad grafik.
- Vapeneffekter och träffzoner.
- **Multiplayer och publik webbadress är ännu inte klara.**

## Utveckling

Spelet ligger just nu i `index.html`. Vi kan senare dela upp koden i flera filer, lägga till automatiska tester och koppla på en multiplayer-server.

## Publicering

Repot är privat. Att spelet finns på GitHub innebär inte att det redan har en publikt spelbar URL.
